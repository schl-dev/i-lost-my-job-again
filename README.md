# I Lost My Job (Again)

Jeu d'entretien d'embauche comique : un recruteur 3D (three.js) juge tes reponses, note l'impression, et tu finis toujours par perdre le job.

Prototype en un seul fichier : ouvrir `index.html` dans un navigateur. Mode hors-ligne automatique si le recruteur IA n'est pas disponible.
