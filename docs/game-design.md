# I Lost My Job Again

## Concept général

I Lost My Job Again est un jeu narratif de simulation d'entretien d'embauche.
Le joueur incarne une personne qui cherche à retrouver un travail après avoir perdu son emploi.

Le cœur du jeu repose sur les entretiens avec des recruteurs contrôlés par une IA.
Le joueur peut répondre librement aux questions, improviser, mentir, se justifier ou se tromper.

Chaque entretien est différent selon :
- l'entreprise ;
- la personnalité du recruteur ;
- les réponses du joueur ;
- son historique professionnel.

L'objectif est de réussir à construire une carrière malgré les échecs.

---

# Boucle principale

1. Le joueur consulte les offres d'emploi.

2. Il choisit une entreprise.

3. Il arrive dans une salle d'attente.

4. Il peut préparer son entretien :
- écrire des notes dans son carnet ;
- relire ses anciennes expériences ;
- observer l'environnement.

5. Il entre dans le bureau du recruteur.

6. Entretien libre avec IA :
- questions ;
- réponses du joueur ;
- réactions du recruteur.

7. Résultat :
- embauché ;
- refusé ;
- deuxième entretien.

8. Le joueur progresse :
- nouveaux emplois accessibles ;
- meilleure expérience ;
- meilleur CV.

---

# Système d'entretien

## Les 4 critères cachés

## 1. Compétence
Déterminée par :
- emplois réussis ;
- expériences passées ;
- réponses adaptées au poste.

## 2. Honnêteté
- Dire la vérité augmente la confiance.
- Mentir peut fonctionner mais peut être découvert.

## 3. Confiance
- Réponses assurées = bonus.
- Contradictions = malus.

## 4. Professionnalisme
- Politesse.
- Respect du recruteur.
- Attitude pendant l'entretien.

---

# Système de carnet

Avant l'entretien :
Le joueur est dans une salle d'attente.

Il possède un carnet où il peut écrire ses propres notes.

Pendant l'entretien :
- touche E pour sortir le carnet.
- maximum 3 utilisations sans conséquence.

Après :
- 4ème utilisation : remarque du recruteur.
- 5ème utilisation : deuxième remarque.
- Maximum 2 remarques par entretien.

Exemples :

"Vous avez besoin de vérifier vos notes ?"

"J'aimerais que vous répondiez plus naturellement."

Après les deux remarques :
les utilisations supplémentaires réduisent discrètement le professionnalisme.

---

# Système de dialogue IA

Le joueur peut parler librement.

Exemples :
- répondre sérieusement ;
- faire de l'humour ;
- changer de sujet ;
- négocier ;
- mentir.

L'IA reste dans le rôle du recruteur.

Si le joueur sort légèrement du contexte :
le recruteur recadre.

Si le joueur adopte un comportement trop déplacé :
- perte importante de confiance ;
- arrêt immédiat de l'entretien possible.

Équipier polyvalent

Aucun.

Teste :
- motivation ;

Prérequis :

- rythme de travail.

---

## 3. Marché Plus
Difficulté : moyenne

Employé polyvalent.

Prérequis :
Expérience client.

# Direction artistique

## Style général

Jeu en 2D animé avec une caméra fixe.

Inspirations :
- roman graphique ;
- visual novel ;
- jeu narratif.

Le joueur observe les scènes comme une pièce de théâtre.

---

# Vue du jeu

POV statique :

- caméra fixe dans chaque scène ;
- personnages animés en 2D ;
- expressions faciales ;
- petits mouvements naturels.

Exemple :

Salle d'entretien :
- bureau au centre ;
- recruteur face au joueur ;
- animations de respiration ;
- regard ;
- gestes des mains.

---

# Animation

Pas de 3D.

Animation 2D avec :
- sprites animés ;
- changements d'expressions ;
- mouvements du visage ;
- réactions pendant les dialogues.

Exemples :
- recruteur regarde ses documents ;
- recruteur soupire ;
- recruteur sourit ;
- recruteur devient sérieux.

---

# Direction artistique visuelle

Ambiance :
- réaliste mais légèrement caricaturale.
- humour dans les situations.
- critique légère du monde du travail.

Couleurs :
- bureaux froids pour les grandes entreprises.
- couleurs plus chaleureuses pour les petits commerces.

---

# Interface

Minimaliste.

Éléments :
- carnet ;
- CV ;
- offres d'emploi ;
- historique des emplois ;
- argent gagné.

---

# Objectif du prototype

Créer une démo courte mais impressionnante :

Contenu :
- 5 entreprises.
- 5 recruteurs différents.
- conversations IA.
- carnet.
- système de réussite/refus.
- progression du CV.

Durée d'une partie :
15-30 minutes.

Le but est de montrer :
"Chaque entretien semble être une vraie conversation."
